# MatrixFlow 产品流程与体验审查

日期：2026-10-10（Asia/Shanghai）。围绕跨境运营团队的核心流程审查：进入工作台、建立 AI 岗位、基于产品资料产出内容、知识问答、执行工作流与复用结果。

## 已完成的改动

| 流程     | 问题                                                                                 | 新行为                                                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 登录     | 2.5 秒的保护页等待容易把慢网络用户送回登录页；网络故障与未登录混为一谈               | 延长身份读取等待；401 转登录并保留安全的原始目标地址；网络故障展示可重试状态                                                                                                       |
| 团队切换 | 共享查询缓存和页面表单可能短暂保留上个团队的数据                                     | 每个账号/团队使用独立 QueryClient；团队切换同步重建页面；受限 sessionStorage 可继续工作，明确清除的上下文不再恢复旧团队                                                            |
| AI 员工  | 只能运行、无法调整岗位；提示“仅基于知识库”却未实际检索资料                           | 可以编辑名称、岗位、指令、关联或解除本团队知识库、暂停/启用；单次模型推理使用当前索引资料，结果保存引用；历史输出可展开、复制、下载                                                |
| 内容工厂 | 输出固定英文；降序历史被旧内容覆盖；短预览无法复用                                   | 选择九种输出语言、目标市场、文风与受众；十二种内容各有结构要求；保留最新版本；复制、展开、下载；新建项目入口直接打开表单                                                           |
| 后台任务 | 页面阻塞等待，用户离开后找不到结果；失败重试引用未定义变量；进程崩溃可能永久 RUNNING | 员工运行、单项/批量内容、知识索引/问答和工作流使用持久任务；自动轮询、取消、部分成功提示、任务详情与来源链接；修复重试变量；任务读取对过期租约进行原子恢复，重试次数耗尽后明确失败 |
| 工作流   | 画布上的修改不一定成为实际运行版本；没有运行输入                                     | 保存当前画布与可见节点配置后运行；支持 JSON 对象输入与字段引用；节点 ID 使用随机 UUID；历史区正确识别 COMPLETED 并提供结果导出                                                     |
| 知识库   | 上传与重建索引等待较长；问答结果只在当前页面                                         | 后台索引与后台问答，保留来源与任务结果；避免重复问答；答案支持复制、下载                                                                                                           |
| 概览     | 为统计数量下载全部资源与文档；某个请求失败使全部统计消失                             | 轻量租户计数，保留可用统计，缺失数据用“—”显示；普通用户界面不再展示适配器协议                                                                                                      |
| 其他体验 | 删除确认默认焦点落在危险操作；客服消息逆序                                           | 删除默认聚焦取消，稳定焦点与滚动锁定，支持键盘；客服对话按时间正序显示                                                                                                             |

权限判断和知识读取均在服务端限制到当前团队。关联知识库通过既有 configuration JSON 存储，无需新增表或字段。原同步 API 调用方式继续兼容；新的浏览器操作选择 async。失败任务只向页面提供稳定错误码，不显示内部异常正文。

## 后续边界

- 当前检索为有边界的词法/混合评分，并非向量检索；大规模资料需要独立索引与检索服务。
- 邮件和外部 webhook 节点仍为受控预览，没有实际发送；支付仍未开放。
- 崩溃任务恢复由任务列表/详情读取触发；没有人在查看时，仍需外部定时巡检才能主动恢复。
- 工作流重试可能再次执行已完成节点；加入真实外部副作用前，需要按节点保存检查点与幂等策略。
- 当前后台取消不能撤回已发出的模型请求；用户可看到取消状态，额度已预留的调用不做虚假的退款。
- 生成文案与回答仍需人工确认，知识引用不代表模型输出一定正确。
- GitHub 自动部署尚缺部署/验收 Secrets；本轮复用本机 CLI 会话验收和发布，不把长期密钥写入仓库。
