## MF92 越野包演示脚本

| 画面       | 演示动作                                                             |
| ---------- | -------------------------------------------------------------------- |
| 商品手册   | 指出容量、重量、材质与护理方式，说明保修期限尚未提供。               |
| 内容工厂   | 建立内容项目、关联已索引的手册，选择 English，生成商品详情页。       |
| 草稿与来源 | 展开来源，对照容量和重量，检查保修说明。                             |
| 审核与导出 | 编辑一处文字，重新确认审核，下载并打开文件，展示最终文字和来源摘录。 |

对外演示使用虚构商品和公开资料。报价、套餐状态和开放范围以[当前定价页](https://matrixflow-ai-sycamore-tree.vercel.app/pricing)为准。
