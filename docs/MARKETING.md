## 5. FAQ（10 条）

**Q: MatrixFlow AI 和 ChatGPT 有什么区别？**
A: ChatGPT 是通用聊天工具，MatrixFlow 是 AI 员工操作系统。你可以创建专属 AI 员工，接入你的产品知识库，配置工作流自动执行，管理团队权限，追踪用量成本。不是对话，是自动化运营。

**Q: 我不懂技术，能用吗？**
A: 完全可以。选择行业模板，上传商品资料，点"生成"就行。不需要写代码、不需要配置 API。Pro 套餐以上有可视化工作流编辑器，拖拽即可。

**Q: 生成的内容质量怎么样？**
A: MatrixFlow 通过统一 Provider 层接入 Anthropic Messages 和 OpenAI Chat Completions，兼容 GLM 等 OpenAI-compatible 网关。每个 Prompt 都经过电商场景调优，内置品牌语气管理和内容评分。你可以随时编辑、评分、迭代。

**Q: 支持哪些电商平台？**
A: MVP 阶段支持 Amazon、Shopify、TikTok Shop 内容生成。输出内容可以复制粘贴到任何平台。后续会接入平台 API 直接发布。

**Q: AI 员工是什么？**
A: AI 员工 = 角色 + 知识库 + 工具 + 工作流。比如"跨境文案专员"这个 AI 员工，懂你的产品（知识库），会用内容生成工具，能按工作流自动执行。你只需下达任务，它自动完成。

**Q: 数据安全吗？**
A: 当前版本在共享数据库中通过组织 ID 实施应用层多租户隔离，并使用测试覆盖关键越权路径；对象存储默认私有。IntegrationAccount 尚未开放业务写入口，启用前必须接入 KMS/信封加密。是否用于模型训练取决于所选 AI Provider 的合同与数据政策，部署方应独立确认。

**Q: 如何计费？**
A: 按套餐月付，包含 AI 调用额度。所有 Provider 的输入/输出 token 用量都会统一记录并可追踪；具体模型费用由团队在对应模型服务商侧控制，产品不会虚构成本或扣款。

**Q: 可以退款吗？**
A: 7 天无理由退款。之后按剩余月份比例退款。

**Q: 团队怎么协作？**
A: 创建团队空间，邀请成员，分配角色（owner/admin/member）。AI 员工和知识库按团队共享，内容和工作流有版本管理。

**Q: 和 n8n/Zapier 有什么区别？**
A: n8n/Zapier 是通用自动化工具，需要你自己搭每个步骤。MatrixFlow 是电商 AI 专用平台：预置行业模板、AI 员工角色、内容工厂 Prompt，开箱即用。不需要从零搭建自动化。
