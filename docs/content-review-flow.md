# 商品内容试用流程

1. 打开内容工厂，填写商品名称与已确认的规格，也可使用示例商品开始。
2. 可选关联当前团队的知识库。先在知识库中上传并完成文档索引，再创建关联项目。关联保存在项目商品资料中；不关联时只使用商品资料。
3. 选择语言、目标市场与文风，先生成一种内容。单项及批量后台生成都会读取项目关联的知识库并保存检索来源。每批共用同一次检索结果。空知识库或无权限来源会在预留 AI 额度前报错。
4. 展开检索来源，对照规格和政策编辑草稿；来源是检索证据，不代表每个生成结论均已验证。
5. 点击「确认审核」后复制或下载。修改文字会清除核对状态，新生成结果也需要重新核对。

点击「保存草稿」可保存当前修改。确认审核会记录审核人、时间和版本。系统保留生成原文，拒绝覆盖他人已保存的更新。正文与带来源的审核记录可分别导出。新稿会记录引用资料的索引版本。资料重建或删除后须重新生成并核对，历史稿只校验来源文档是否仍可用。

在原项目点击「编辑商品资料」可更新规格。旧版本文案会保留供参考，审核和导出需要基于最新资料重新生成。Shopify 译文则以导入批次的原文和资料来源为准。

验证覆盖关联知识库的租户边界、空库错误、示例入口、关联参数、生成结果重载、编辑后重新确认和导出内容。浏览器测试使用模拟业务服务；生产真实商品质量与引用准确率需独立验收。

删除开始后，项目暂停接收新稿件。清理中断时，可在内容工厂选择该项目继续删除。已完成并保存的稿件随项目一起清理。

## 引用与输出语言

短文档在一个分块可容纳全文时不再按末尾换行重复切分。检索会合并同一文档中被完整包含的重复片段，兼容历史索引；含有不同事实的重叠段落仍保留。已生成内容不会被自动改写，重新生成后使用新的引用选择。

检索会把长分块切成较短的片段，再匹配关键词。保存的每条引用均对应送入模型的一段资料，摘要优先显示命中词附近的原文。

内容生成的语言约束覆盖正文、标题、说明、缺失项和来源注释。英文缺失项使用 `Not provided` / `To be confirmed`；来源文件名、品牌和标识允许保留原文。“多语言翻译”仍按明确要求生成英、德、法、西四个版本。提示词回归测试不能替代真实模型的输出质量验收。

## Shopify 翻译表交付

在内容项目打开「Shopify 翻译」，选择店铺后台「设置 → 语言」导出的 UTF-8 CSV。预览显示可导入与跳过的行数。每次最多 40 个商品字段，支持 `title`、`body_html`、`meta_title` 和 `meta_description`。每家店铺使用独立项目。

导入按商品标识、字段、语言和市场识别同一行。原文、原有译文或原审核状态变化会清除审核，未变的已审译文可复用。关联知识库时，检索不到对应资料或发现明确标注的容量、重量相互冲突，会提示核对。系统会检查 AI 译文的数字、HTML 和占位符；失败的字段可以重试或手工编辑。

「翻译剩余空白字段」会在任务中心创建后台任务，关闭页面后仍可运行。任务按字段记录进度并跳过已被人工修改的字段。任务完成或取消后都会保留已完成的译文。可以从任务详情返回项目，核对结果并导出已审核译文。

只回传当前所选批次的已审核行，原始列、商品标识和未知附加列均保留。下载的 JSON 审核记录单独保存。建议先在开发店铺验证少量行，再按店铺实际语言和覆盖选项导入。格式依据 [Shopify 官方说明](https://help.shopify.com/en/manual/international/languages/csv-translations)。
